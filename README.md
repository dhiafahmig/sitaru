# **Sistem Informasi Layanan Pengaduan Tata Ruang**  
*(Laporan Pengaduan Berbasis Web dengan CodeIgniter 3 & Leaflet JS)*  

🔍 **Deskripsi**  
Sistem ini dibangun untuk mempermudah masyarakat dalam melaporkan masalah tata ruang (bangunan liar, pelanggaran IMB, dll) secara online dengan fitur pelacakan lokasi berbasis peta (Leaflet JS).  

---

## **🛠 Teknologi yang Digunakan**  
- **Backend**:  
  - PHP (CodeIgniter 3)  
  - MySQL (Database)  
- **Frontend**:  
  - Bootstrap 4  
  - Leaflet JS (Peta Interaktif)  
  - jQuery & AJAX  

---

## **🎯 Fitur Utama**  
1. **Autentikasi Pengguna**  
   - Login multi-level (Admin, Petugas, Masyarakat)  
   - Registrasi akun masyarakat  
2. **Pengaduan Online**  
   - Input laporan + lokasi (drag marker di peta)  
   - Upload bukti foto  
3. **Pelacakan Status Pengaduan**  
   - Notifikasi email/WhatsApp (jika terintegrasi)  
   - Riwayat pengaduan per user  
4. **Dashboard Admin**  
   - Analisis data pengaduan (grafik)  
   - Export laporan (PDF/Excel)
